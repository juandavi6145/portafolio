# Evaluación de Ensayo de Hormigón

## Propósito
Este proyecto organiza y documenta los resultados de un ensayo de hormigón heredado, asegurando su trazabilidad y reproducibilidad para futuras auditorías.

## Entradas y Datos
* `Datos/ensayo_hormigon.xlsx`: Datos brutos del ensayo original.

## Procedimiento y Análisis
* `Análisis/ensayo_hormigon_FINAL_v2.xlsx`: Planilla con los cálculos y el análisis de los datos procesados.

## Salidas y Herramientas
* `Figuras/grafico_final.png`: Representación gráfica de los resultados finales.
* `Documentación/informe_final.docx`: Informe descriptivo del proyecto.
* Las herramientas utilizadas incluyen hojas de cálculo y procesadores de texto estándar.

## Limitaciones y Supuestos
* Se asume que los datos originales provienen de condiciones de laboratorio controladas.
* El proyecto fue heredado, por lo que las iteraciones previas a la versión V2 no poseen trazabilidad completa de los cambios realizados.
