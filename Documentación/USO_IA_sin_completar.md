# Uso de IA

* **Herramienta:** Gemini (Modelo de lenguaje de Google).
* **Propósito:** Asistencia metodológica para organizar la estructura de carpetas del repositorio, redactar el archivo README.md y estructurar las respuestas de la bitácora.
* **Salida utilizada:** Sugerencias de estructura de carpetas y textos base para la documentación técnica.
* **Cómo se verificó:** Toda sugerencia fue leída, comprendida y contrastada manualmente con el archivo `Checklist_revision_portafolio_U1.docx` y los criterios de la rúbrica de evaluación para asegurar su cumplimiento.
* **Decisión final:** Se incorporaron los textos sugeridos al README y a la bitácora, descartando aquellos que no aplicaban a las limitaciones del proyecto.
